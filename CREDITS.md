# Credits

IsaClient stands on a lot of other people's work. Thank you all.

## Where it comes from

- **Terraria** by [Re-Logic](https://re-logic.com). The game, and the reason any of this exists.
- **[TerraAngel](https://github.com/UnrealMultiple/TerraAngel)** (MIT). The plugin API and the TerraAngel pack in `plugins/` are theirs.
- **[ZazaMod](https://youtu.be/UItObM05crs)**, the client IsaClient started from.
- **[tModLoader](https://github.com/tModLoader/tModLoader)**. Some of its ideas were used here.
- **WldFlow**, for how map reveal and protected chests work.
- **[TEdit](https://github.com/TEdit/Terraria-Map-Editor)**, for the schematic format.
- **Terraria Pixel Art Generator**, whose block matching the pixel art tool reproduces.

## What runs inside

- **[mGBA](https://github.com/mgba-emu/mgba)** (MPL 2.0), the Game Boy Advance core.
- **[PPSSPP](https://github.com/hrydgard/ppsspp)** (GPL 2.0), the PSP core, downloaded on demand.
- **[libretro](https://www.libretro.com)**, the API both cores speak.
- **[Dear ImGui](https://github.com/ocornut/imgui)** and **[ImGui.NET](https://github.com/ImGuiNET/ImGui.NET)**, the plugin UI.
- **[Harmony](https://github.com/pardeike/Harmony)**, runtime patching for plugins.
- **[Roslyn](https://github.com/dotnet/roslyn)** and **[ILSpy](https://github.com/icsharpcode/ILSpy)**, to compile and convert plugins.
- **[yt-dlp](https://github.com/yt-dlp/yt-dlp)**, behind the music and video players.
